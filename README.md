# Выдержка

Дуэль намерений: покажи приём, тайно сыграй настоящий, держи слово или блефуй — и найди привычку соперника.

- `index.html` — игра, открывается в любом браузере (в том числе на телефоне).
- `src/game.html` — исходник игры. После правок пересобрать `index.html`: `sh tools/build.sh`.
- `docs/duel-rules.md` — правила и дизайн игры (живой документ с историей изменений).
